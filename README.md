# NovaSoft - Sistema de Gestión de Pedidos

Sistema web sencillo para registrar pedidos de clientes y calcular su total.
Desarrollado en HTML, CSS y JavaScript puro (sin dependencias) como parte de la
actividad "Gestión de versiones - NovaSoft" de la asignatura Gestión de la
Configuración de Software.

## Funcionalidades

- Registro de pedidos (cliente, producto, cantidad).
- Cálculo del total del pedido.
- Formato de valores monetarios.

## Cómo ejecutar

Abrir `index.html` en cualquier navegador moderno.
